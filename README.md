# HTML and CSS Assignment Dashboard
About the Project

This project is an Assignment Dashboard created using HTML and CSS. It displays different assignment buttons on the left side and opens the selected assignment on the right side using an iframe.

# Technologies Used
HTML5
CSS3
# Features
Simple and attractive dashboard layout
Nine assignment buttons
Blue buttons with white text
Left-side vertical navigation menu
Right-side iframe to display assignments
Flexbox layout for alignment
Easy navigation between assignments
Assignments Included
Assignment 1: Background Design
Assignment 2: Newspaper
Assignment 3: HTML and CSS Assignment
Assignment 4: Dynamic Image Gallery
Assignment 5: Profile Card UI/UX Design
Assignment 6: Home Page
Assignment 7: Navigation Bar
Assignment 8: Table
Assignment 9: Box Design
# How to Run
Save the main code as index.html.
Keep all assignment HTML files in the same project folder.
Open index.html in a web browser.
Click any assignment button to display its page in the iframe.
